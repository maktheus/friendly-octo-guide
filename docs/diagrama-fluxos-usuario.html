Mapeamento de Fluxos de Usuário & Endpoints HTTP — TECEMI 4.0

Mapeamento interativo dos fluxos de trabalho e URLs diretas de acesso para cada persona na plataforma SMT.

Chão de Fábrica & Operação de Linha

1. Operador da Linha SMT (Produção & Inspeção)

Acompanha o fluxo contínuo das máquinas SPI, Pick-and-Place e AOI. Exige interface sem atrito, respostas rápidas (<15ms) e confirmações imediatas de refugo.

🚀 Acessar IHM do Operador SMT http://localhost:8080/ihm/operador
1
Autenticação Rápida IHM
POST http://localhost:8080/api/v1/auth/login
Validação de matrícula + TOTP 6 dígitos no YARP API Gateway com emissão de token JWT (5 min).
2
Alerta de Visão SPI/AOI em Tempo Real
POST http://localhost:8080/api/v1/vision/inspect
Trabalhador Ai.Worker.Vision processa a imagem no modelo YOLO11s e envia o alerta de "Falta de Solda no C12".
3
Registro de Refugo no MES Legado
POST http://localhost:8080/api/v1/mes/events
O Mes.Connector dispara evento SQL Dapper para registrar a placa descartada no MES da fábrica.
Análise Causal & Qualidade 6M

2. Engenheiro de Processo & Qualidade

Investiga picos de defeitos, realiza buscas semânticas em vetores `pgvector` e avalia regras Ishikawa 6M com explicabilidade auditável (XAI).

🚀 Acessar Portal de Diagnóstico GraphQL (Banana Cake Pop) http://localhost:5000/graphql
1
Consulta Vetorial de Causas Raízes (pgvector)
POST / GraphQL http://localhost:5000/graphql
Executa a query query { consultarCausaRaiz(sintoma: "Ponte de solda") } com busca por similaridade HNSW.
2
Avaliação do Motor de Regras Ishikawa 6M (XAI)
POST / GraphQL http://localhost:5000/graphql
Executa a query query { avaliarRegrasIshikawa }, retornando a árvore de dedução causal 6M.
3
Integração com Chatbot MCP
POST http://localhost:5002/mcp/tools/avaliar_regras_ishikawa
Assistente virtual executa a ferramenta MCP para responder perguntas em linguagem natural ao engenheiro.
Preditiva & Saúde de Ativos

3. Engenheiro de Manutenção Preditiva

Monitora o desgaste de motores, temperatura do forno de reflow e executa predições com trava atômica de idempotência.

🚀 Acessar Painel Preditivo iDMSS http://localhost:8080/portal/manutencao
1
Avaliação Preditiva iDMSS
POST http://localhost:8080/api/v1/predictive/evaluate
Modelo Gradient Boosting + SMOTE calcula a probabilidade de falha em componentes mecânicos.
2
Consulta de Idempotência Valkey Ledger
GET http://localhost:8080/api/v1/admin/valkey-ledger
Verifica as travas distribuídas atômicas (`SET NX` com TTL) que evitam re-processamento duplicado de falhas.
Visão Estratégica & Métricas OEE

4. Gerente de Fábrica / Diretor de Operações

Consome visões consolidadas do OEE (Eficiência Global do Equipamento), First Pass Yield (FPY) e relatórios institucionais.

🚀 Acessar Dashboard Executivo Grafana OEE http://localhost:3000
1
Dashboard de OEE & Métricas Globais
GET http://localhost:8080/api/v1/metrics/oee
Renderiza o indicador de Eficiência Global dos Equipamentos consolidado das linhas SMT.
2
Consulta de Eventos Históricos Parquet
GET http://localhost:8080/api/v1/archiver/summary
Serviço Data.Archiver lê históricos em arquivos Parquet de alta compactação no S3.
Infraestrutura, Segurança & SecOps

5. Administrador de TI / Engenheiro DevOps & SecOps

Garante a saúde dos 16 microsserviços C#, rotação de segredos no OpenBao e monitoramento OpenTelemetry.

🚀 Acessar Orquestrador .NET Aspire Dashboard http://localhost:18888
1
Dashboard Orquestrador .NET Aspire
GET http://localhost:18888
Painel central do Aspire com status dos 54 projetos C# e métricas OpenTelemetry (OTel).
2
Documentação Interativa Swagger API Gateway
GET http://localhost:8080/swagger
Interface Swagger OpenAPI do Gateway YARP para testes e documentação de contrato.
